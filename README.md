# Corporate Website Theme

A custom WordPress theme for a corporate website, with reusable page templates, responsive layouts, product and service pages, and a portfolio powered by WordPress projects.

## Requirements

- WordPress 6.0 or later
- PHP 7.4 or later

## Installation

1. Copy the theme folder into `wp-content/themes/`.
2. In WordPress, go to **Appearance → Themes** and activate the theme.
3. Create the site pages and assign the appropriate templates from the page editor.
4. Configure the navigation menus under **Appearance → Menus**.

The theme has no build step or package manager requirements. Its PHP, CSS, JavaScript, fonts, and bundled image assets are served directly from the theme folder.

## Included templates and features

- Home, company/about, contact, products, plans, resellers, academy, and service pages
- Dedicated product pages for Weld VR, Forklift VR, Firefighter VR, and Electro VR
- Portfolio archive and editable portfolio page templates
- Custom portfolio projects with featured images, project details, and sector/technology groupings
- Shared site header, footer, contact call-to-action, and project-grid components
- Responsive styling and interactive navigation and page components

## Portfolio images

Portfolio projects use their WordPress featured image for project cards and detail pages. Add or update featured images through the project editor in WordPress. The site’s uploaded portfolio media is stored in the WordPress uploads directory and managed by the site’s Media Library.
